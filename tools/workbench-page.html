            About this build
            

            

              These lessons compile small, freestanding C edits with a
              WebAssembly build of Tiny C Compiler. The edited object is
              incrementally linked into a reserved area of an otherwise
              native-built xv6 image. This is a real compiled executable, with a
              bounded source and object size; it is not a full
              make rebuild.
            

            

              Every run boots a fresh, disposable machine. Guest files reset;
              source drafts stay saved.
            

            

              Kernel instruction helpers execute the native RISC-V register and
              atomic instructions that this C compiler cannot assemble inline.
              Their
              complete source
              is included with the kernel.
