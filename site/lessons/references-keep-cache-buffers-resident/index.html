References keep cache buffers resident

Observe real pin counts and balance their lifetime.

Compiler and kernel run locally.
Your source stays in this browser.

A valid cached block can still be recycled once nobody references it. A pin adds a reference that survives an ordinary brelse. The journal uses this to retain modified buffers until commit has copied their final bytes.

The probe holds a real buffer, adds one pin, reads the change in refcnt, then balances the pin and its original bread reference. Build and observe 1. Change PINS to 2 to observe two real additional references.

A pin does not itself grant the content lock, write the disk or make an inode persist. These are separate protocols. Leaving a pin unbalanced can exhaust the fixed cache by making buffers permanently ineligible for recycling.

C reminder: loops and bounds

The initialiser runs once, the condition is checked before each iteration, and i++ advances the index afterwards. With i < count, the visited indices are 0 through count - 1. The array must have enough elements for those accesses.

for (int i = 0; i < count; i++) {
  /* use element i */
}
