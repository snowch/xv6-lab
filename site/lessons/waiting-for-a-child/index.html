wait collects an exited child

Use wait to collect a child that has finished.

Compiler and kernel run locally.
Your source stays in this browser.

A child can finish before its parent asks about it. xv6 keeps a small record of the exited child until its parent calls . This exited-but-uncollected state is called ZOMBIE. The child’s user program has finished.

wait(0) returns an exited child’s PID and releases the resources retained for it. If a child is still running, wait puts the parent to sleep until a child exits. If the parent has no children, wait returns -1.

The parent’s final message is after wait. You can rely on the child having exited before that message. With several children, wait can collect any exited child; this example creates exactly one.

C reminder: addresses passed to functions

&status gives the address of the caller’s variable, so a function can write a result there. The function’s return value is a separate result. A zero used as a pointer argument is a null pointer; wait(0) supplies no status address.

int status = 0;
int pid = wait(&status);
