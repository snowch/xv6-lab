A system call returns a result

Read the process identifier returned by getpid.

Compiler and kernel run locally.
Your source stays in this browser.

A process sometimes needs information held by the kernel. A system call is a request from a user program to the kernel. is a small example: it returns the identifier of the process making the call.

The program passes that returned integer to printf. The %d placeholder prints it as a decimal number. The kernel’s process record also stores a PID; the evidence beside the console reads that real record during this run.

Build the unchanged program. Compare its reported pid with the observed kernel PID. They should agree. You need not know the number in advance.

C reminder: arguments and return values

A call such as f(x) passes an argument to a function. return supplies its result. In a nested call, the inner result becomes an argument to the outer call; assigning the result to a variable can make that easier to read.

int pid = getpid();
printf("reported pid=%d\n", pid);
