A system call returns a result

Does the number returned by getpid match the PID stored in the kernel?

A system call is a request from a user program to the kernel. returns the process identifier, or PID, of the caller.

The program passes that integer to printf. The %d placeholder prints it as a decimal number. The lab also reads the stored PID from the kernel’s process record while this code runs.

C reminder: arguments and return values

A call such as f(x) passes an argument to a function. return supplies its result. In a nested call, the inner result becomes an argument to the outer call; assigning the result to a variable can make that easier to read.

int pid = getpid();
printf("reported pid=%d\n", pid);
