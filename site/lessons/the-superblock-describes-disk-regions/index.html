The superblock describes disk regions

Distinguish the whole image from its data-block region.

xv6 divides its disk into a boot block, superblock, log, inode blocks, bitmap and data blocks. The superblock records their sizes and starting positions. fsinit reads it from block 1 and checks its magic before using the filesystem.

The probe reads the actual in-memory superblock loaded from this image. size counts all 1000 blocks. nblocks counts the 954 blocks in the data region. That region contains both allocated and unallocated blocks: nblocks is not a count of currently free space.

The source shows how mkfs describes the format; later pages follow the bitmap that tracks allocation within it.

C reminder: struct members and output arguments

The dot operator reads a member of a struct value. &st passes its address so fstat can fill it. Check that the call succeeded before reading those fields; declaring a local struct alone does not initialise its contents.

struct stat st;
if (fstat(fd, &st) == 0)
  printf("links=%d\n", st.nlink);
