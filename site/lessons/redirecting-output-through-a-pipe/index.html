Redirection changes the destination

Run echo with its standard output connected to a pipe.

A program like echo writes to descriptor 1. A shell can change what that descriptor points to before starting the program, without changing echo’s code.

The child closes its console descriptor 1, then duplicates the pipe writer. Because 1 is the lowest free slot, dup places the writer there. Closing the original pipe descriptors leaves standard output as the child’s writer reference.

exec preserves those descriptor connections. Echo’s bytes enter the pipe; the parent loops until EOF to collect the short message. This combines fork, close, dup and exec from the preceding lessons.

C reminder: assignment inside a loop condition

The parenthesised assignment first stores the read result in n. The > 0 comparison then decides whether to enter the loop. Use only the n bytes actually returned; a request for a larger count does not promise that many bytes arrived.

while ((n = read(fd, buf, sizeof(buf))) > 0) {
  /* consume buf[0] through buf[n - 1] */
}
