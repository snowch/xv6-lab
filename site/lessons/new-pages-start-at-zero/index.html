New user pages start at zero

Observe the zeroing performed when xv6 allocates user pages.

Physical memory can be reused after another process releases it. Before mapping a newly allocated page into this process, xv6 fills that page with zero bytes.

The example reads every byte in a newly requested page and counts nonzero values. It should find none. This is a property of newly allocated user pages, not a claim that every C local variable begins at zero.

The zeroing happens in uvmalloc, before the new mapping is made available to user code. It prevents a new allocation from exposing the previous contents of that physical page.

C reminder: loops and bounds

The initialiser runs once, the condition is checked before each iteration, and i++ advances the index afterwards. With i < count, the visited indices are 0 through count - 1. The array must have enough elements for those accesses.

for (int i = 0; i < count; i++) {
  /* use element i */
}
