A child returns an exit status

Distinguish wait’s returned PID from the child’s exit status.

Compiler and kernel run locally.
Your source stays in this browser.

The argument to is the child’s exit status: an integer it leaves for its parent. Zero conventionally means success; a program can use other values to describe another outcome.

The parent supplies &status to wait. In C, this is the address of its local status variable. xv6 copies the child’s exit status there before collecting the child. Passing 0, as on the previous page, skips that copy.

There are two results to keep apart: the value wait returns is the child’s PID; the value it writes into status is the integer the child passed to exit.

C reminder: addresses passed to functions

&status gives the address of the caller’s variable, so a function can write a result there. The function’s return value is a separate result. A zero used as a pointer argument is a null pointer; wait(0) supplies no status address.

int status = 0;
int pid = wait(&status);
