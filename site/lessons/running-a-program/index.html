A running program is a process

Distinguish a program’s source from a running process.

Compiler and kernel run locally.
Your source stays in this browser.

A program is a set of instructions. A process is a running instance of a program, with its own memory and state. The operating system creates and manages processes.

The source below is a small C program for xv6. Execution starts in . It prints a message, then calls to end the process. The zero is an exit status conventionally used for success.

Choose Build & run. The browser compiles your C to RISC-V instructions and boots a fresh xv6 machine. The xv6 shell is a program that reads commands and starts other programs. Here it starts your program as a process. After it exits, the shell prints its $ prompt again.

C reminder: reading a small C program

main is the program’s entry function. Statements end with semicolons, and braces group a function or branch body. In printf, %d formats an integer and \n starts a new line.

int n = 3;
printf("n=%d\n", n);
