A running program is a process

What starts your program, and which program stays running when it exits?

A process is a running instance of a program, with its own memory and state. The operating system manages processes. Its kernel is the part that controls access to memory and devices and decides which process runs.

The browser compiles C to RISC-V instructions and runs them on a virtual machine that emulates a RISC-V processor. After xv6 boots, its shell reads the supplied workbench command and starts your program at . The program prints a message, then calls to end its process. An exit status of zero usually means success.

C reminder: reading a small C program

main is the program’s entry function. Statements end with semicolons, and braces group a function or branch body. In printf, %d formats an integer and \n starts a new line.

int n = 3;
printf("n=%d\n", n);
