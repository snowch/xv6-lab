Sleep waits for guest timer ticks

Observe a timed sleep without treating it as a browser performance measurement.

xv6’s waits for guest timer ticks. While the process sleeps, the CPU can run another process. uptime() reads the kernel’s count of those ticks.

The example records a starting count, requests three ticks, then checks that at least that many elapsed. More ticks may pass before the process runs again. There is no promise of an exact browser duration.

In the kernel, the sleep syscall remembers ticks0 and repeatedly checks the condition. Kernel sleep blocks on the ticks channel between checks; timer handling advances the count and wakes sleepers.

C reminder: arguments and return values

A call such as f(x) passes an argument to a function. return supplies its result. In a nested call, the inner result becomes an argument to the outer call; assigning the result to a variable can make that easier to read.

printf("reported pid=%d\n", pid);
