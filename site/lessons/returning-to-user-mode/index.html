Returning to user mode restores a protected context

Connect the return-mode bits to actual execution, and distinguish a kernel panic from a contained user fault.

usertrapret prepares another boundary crossing. It disables interrupts during setup, selects the trampoline entry for the next user trap, records kernel state in the trapframe, sets the saved return PC, and jumps to the trampoline’s userret code.

The SPP bit chooses the privilege used by sret: clearing it requests user mode. The code also prepares SPIE, the saved interrupt-enable bit. The trampoline switches page tables, restores user registers and executes sret. This is more than an ordinary C return.

The lab setting applies only when returning to workbench. The starter selects user mode. Setting SPP instead requests supervisor execution at user code. The user-page execution restriction causes a trap, and usertrap rejects that unexpected supervisor origin with a kernel panic.

A kernel panic affects the whole machine. The lab stops that virtual machine after showing its complete panic line, while keeping your source and build.

C reminder: setting and clearing flag bits

x |= flag sets the selected bits while preserving others. x &= ~flag clears those bits: ~ complements the mask, then & keeps the remaining bits. The compound assignments update x; a comparison such as (x & flag) == 0 only reads it.

x &= ~flag;  // clear
x |= flag;   // set
