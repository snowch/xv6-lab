Reads advance an open file’s offset

Follow two reads through successive bytes of a regular file.

Compiler and kernel run locally.
Your source stays in this browser.

An open regular file has an offset: the position where its next read or write begins. A successful read advances it by the number of bytes actually read.

The example writes abcd, closes the file, then opens it for reading. A new open starts at offset zero. Two reads of two bytes produce ab, then cd.

The three-byte C buffer leaves room for a zero terminator so printf can display each result as a string. Clearing the buffer between reads separates this C bookkeeping from the kernel’s file offset.

C reminder: buffers and string terminators

The array has six char elements, initially all zero. Reading at most five bytes leaves the final element zero, so the displayed text remains terminated. read reports bytes obtained; it does not append a C string terminator for you.

char buf[6] = {0};
int n = read(fd, buf, 5);
