Parent and child have separate memory

Observe a child change its own copy of an ordinary variable.

Compiler and kernel run locally.
Your source stays in this browser.

The parent and child start with the same ordinary variable values. That does not mean they share the same user memory. In this xv6 version, copies the parent’s user memory into the child’s address space.

The child changes to 99, then exits. The parent waits for that to happen and reads its own value, which remains 7. Waiting establishes that the child has finished; it does not copy the child’s variables back.

The kernel passes different page tables to uvmcopy below. A page table describes which memory belongs at each address in a process. The memory chapter will examine that mapping; here observe its consequence for one C variable.

C reminder: variables and assignment

A declaration such as int value = 7 creates and initialises a variable. A later assignment changes that variable’s value. The braces show which branch contains the assignment; they are important when following parent and child paths.

int value = 7;
if (child == 0) { value = 99; }
