Chapter 8 · Address translation · Lesson 1 of 8

A virtual address selects indices and an offset

Split an address into the fields used by Sv39 translation.

A virtual address is not a physical RAM address. In Sv39, the RISC-V address translation scheme used here, the low 12 bits select a byte within a 4096-byte page. Three fields of nine bits select entries in three levels of page tables. Nine bits select one of 512 entries.

The PX(level, va) macro extracts an index by shifting and masking. The chosen address is a number for this calculation; this first experiment does not claim that it is mapped.

xv6 uses the lower positive half of the Sv39 address range, below MAXVA, to avoid sign-extension complications. We follow its ordinary 4 KiB mappings here. In these lessons, the edited getpid handler is a temporary inspection hook: the supplied user program calls it, the handler prints its observations, then returns the real PID unless the lesson explicitly changes that result.

C reminder: extracting fields with shifts and masks

Right shift discards low bits, and bitwise & keeps the bits selected by a mask. 0x1ff has nine low bits set; 4095 has twelve. A cast to int makes these small extracted values suitable for printf’s %d argument.

int index = (int)((va >> 12) & 0x1ff);
int offset = (int)(va & 4095);
