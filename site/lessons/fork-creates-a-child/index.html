fork creates a child process

Follow one fork call as two processes continue from it.

Compiler and kernel run locally.
Your source stays in this browser.

In Chapter 1, a process asked the kernel for information. Now it asks the kernel to create another process. creates a child of the calling process, which becomes the parent.

On success, both continue just after the same call. The child receives 0; the parent receives the child’s PID. That lets if (child == 0) choose the child’s work. A negative result means creation failed, so the example handles that before either success branch.

The parent uses wait(0) to wait for its child to exit before printing the final line. wait returns the collected child’s PID. The zero means it does not request an exit status. We will examine wait on the next page; here it keeps the example’s output together.

C reminder: comparisons and branches

== compares two values; = assigns a value. if chooses a branch when its condition is nonzero. A test for a negative result is separate from a test for zero, which matters when an interface uses different outcomes for each.

if (child < 0) { /* creation failed */ }
if (child == 0) { /* child’s path */ }
