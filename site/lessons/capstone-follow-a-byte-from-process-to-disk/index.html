Follow a byte from a process to disk and back

Connect process, pipe, file, journal and loader paths in one working program.

The child sends bytes through a pipe. The parent reads the stream until EOF, writes those bytes to a real file, collects the child and replaces itself with native cat to read the file back. The console reports child status and the count of transferred bytes before cat prints the file.

Open Trace one path at a time and select kernel/file.c. In filewrite, compare the pipe branch, which calls pipewrite, with the regular-file branch, which calls writei inside a journal operation. Commit submits actual VirtIO requests, whose interrupts wake blocked work. Checked copies connect the user buffers to those kernel paths.

The last exec loads cat into a new user address space and sets its entry arguments. The console output comes from that replacement program reading the file.

C reminder: assignment inside a loop condition

The parenthesised assignment first stores the read result in n. The > 0 comparison then decides whether to enter the loop. Use only the n bytes actually returned; a request for a larger count does not promise that many bytes arrived.

while ((n = read(fd, buf, sizeof(buf))) > 0) {
  /* consume buf[0] through buf[n - 1] */
}
