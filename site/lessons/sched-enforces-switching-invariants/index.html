Sched checks the handoff contract

Trigger a real guard against switching without the process lock.

Compiler and kernel run locally.
Your source stays in this browser.

Kernel context switching needs a strict contract. sched requires the current process’s lock, exactly one push_off nesting level, a state other than RUNNING, and interrupts disabled. The source below checks all four before switching stacks.

yield establishes that contract for a runnable process. sleep and exit establish their own state transitions before calling sched. These checks prevent a scheduler from observing an inconsistent state or letting two execution paths use the same kernel stack.

Build the starter to complete a normal round. Then bypass yield and call sched directly from this syscall handler. The first check fails with the real kernel panic sched p->lock. This is a deliberate failed kernel: restore the starter and build a fresh machine to continue.

C reminder: arguments and return values

A call such as f(x) passes an argument to a function. return supplies its result. In a nested call, the inner result becomes an argument to the outer call; assigning the result to a variable can make that easier to read.

int pid = getpid();
printf("reported pid=%d\n", pid);
