Nested critical sections restore the previous interrupt state

Observe that the outermost pop restores the original enable state.

A device interrupt could try to acquire a spinlock already held by the code it interrupted. On one hart, spinning in that interrupt would prevent the interrupted holder from ever releasing it. xv6 disables local interrupts while holding spinlocks.

Critical sections can nest. push_off saves the previous interrupt-enable state only at nesting depth zero, then increments noff. pop_off decrements it and restores delivery only when the outermost level ends and the saved state allowed interrupts.

The probe reads the enable bit after the inner and outer pop calls. The final cleanup explicitly reinstates this handler’s known normal entry state; general callers should preserve their own state through matched nesting.

C reminder: arguments and return values

A call such as f(x) passes an argument to a function. return supplies its result. In a nested call, the inner result becomes an argument to the outer call; assigning the result to a variable can make that easier to read.
