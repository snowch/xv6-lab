A killed sleeper must run to exit

Follow cancellation from the killed flag through runnable state to exit.

xv6’s marks the selected process as killed. If it is sleeping, the kernel makes it runnable so it can notice the flag and finish the exit path.

The example gives the child a longer sleep and has the parent request cancellation after one tick. The child should not reach its completion message. The parent collects its exit status -1.

This mechanism is a flag and kernel checks, not immediate deletion of a process record by the caller. If no process has the requested PID, kill returns -1 and changes no target.

C reminder: comparisons and branches

== compares two values; = assigns a value. if chooses a branch when its condition is nonzero. A test for a negative result is separate from a test for zero, which matters when an interface uses different outcomes for each.

if (child < 0) { /* creation failed */ }
if (child == 0) { /* child’s path */ }
