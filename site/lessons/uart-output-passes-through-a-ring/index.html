Buffered output separates a writer from the UART

Change a byte entering the actual kernel transmit ring.

Compiler and kernel run locally.
Your source stays in this browser.

A user write reaches uartputc through the console driver. The kernel places its character in a transmit ring and advances the write counter. uartstart sends queued bytes when the device can accept them; the interrupt handler calls it again as progress becomes possible.

A full software ring makes the process sleep on the read counter while releasing uart_tx_lock. Advancing the read side wakes writers. This is distinct from a user program spinning on a device register.

The editable function is the real uartputc. The small marker transformation happens before its ordinary ring operations. Build and find marker=@ from the supplied user program. Changing the replacement makes the different byte pass through the same ring and device path. Kernel printf uses the separate synchronous routine, so its diagnostic output is not this user-output ring.

C reminder: remainder and array indices

The % operator gives the remainder. For a nonnegative counter, counter % 32 selects an index from 0 to 31 in a 32-element array. The counter itself can keep increasing while the selected array slot wraps around. A character constant such as '@' has an integer character-code value.

int slot = counter % 32;
buffer[slot] = c;
