Exec builds a new argument vector

Follow copied strings and user pointers into the replacement program.

An exec caller supplies pointers into its old address space. The replacement cannot keep using those old pointers after its image is freed. xv6 copies the argument strings into the new user stack and creates a new array of pointers to those copies.

ustack is a temporary kernel array containing new user addresses. Its final zero entry terminates argv. copyout writes both strings and the pointer array through the new page table, before that table becomes the process’s active image.

This program execs its own file once with two extra arguments. The replacement enters main with argc=3 and prints the copied strings. The new argc prevents repeated self-exec.

C reminder: arrays of string pointers

args is an array whose elements point to strings. The final 0 is a null pointer marking the end of the argument list. Each string also has its own zero-byte terminator; these are two different uses of zero.

char *args[] = {"echo", "hello", 0};
