Argument helpers decode saved registers

Change a decoded integer argument while leaving the user request unchanged.

Compiler and kernel run locally.
Your source stays in this browser.

The syscall’s C handler has no ordinary C parameters for the user’s arguments. Helpers retrieve them from the saved user argument registers. argraw selects a0 through a5; argint converts the selected value to an int and writes it through a kernel pointer.

argint’s returned 0 is its own success result. The decoded argument is the separate value written through ip. sys_sleep uses that output as its requested tick count.

The supplied user program always requests sleep(2). The added code adjusts only argument 0 of that syscall. With extra 0, build and observe decoded sleep ticks=2. Changing extra to 3 makes the kernel use five ticks. The elapsed guest ticks should be at least five; scheduling can make them larger, so do not expect an exact duration.

C reminder: writing through an output pointer

An int * parameter holds the address of an integer owned by the caller. Assigning to *ip writes that integer. The function’s return value is separate: returning 0 can report success while the decoded number is delivered through the pointer.

int fill(int *out) {
  *out = 7;
  return 0;
}
