An enable bit controls supervisor interrupt delivery

Observe the supervisor interrupt-enable state around a bounded kernel probe.

Compiler and kernel run locally.
Your source stays in this browser.

An interrupt source can be pending while delivery is masked. The supervisor SIE bit controls whether supervisor interrupts may interrupt supervisor execution. Masking delivery does not erase the device’s request, and machine-mode interrupts are a separate privilege level.

usertrap enables interrupts before calling a syscall handler, so this narrow probe begins with SIE set. intr_off clears it; intr_on sets it again. Build and observe before=1, during=0 and after=1 through actual CPU-register reads.

This explicit off/on pair is suitable for this known starting state. General kernel critical sections need to preserve the previous state and handle nesting; xv6’s push_off/pop_off mechanism does that, and the locking chapter examines it. Enabling interrupts blindly is not a substitute for restoring the caller’s state.

C reminder: arguments and return values

A call such as f(x) passes an argument to a function. return supplies its result. In a nested call, the inner result becomes an argument to the outer call; assigning the result to a variable can make that easier to read.

int pid = getpid();
printf("reported pid=%d\n", pid);
