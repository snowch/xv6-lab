An atomic swap returns the old value

Observe the read-and-write operation used to claim a spinlock.

A spinlock needs to test whether a word is free and claim it as one indivisible operation. A separate load followed by a store would let two CPUs both observe zero before either stores one.

xv6 uses an atomic exchange: it writes 1 and returns the previous value. Returning 0 means this attempt claimed an unlocked word; returning 1 means someone already held it. acquire repeats the exchange until it observes 0.

The native instruction helper executes the real atomic operation. The probe reports the value returned by each exchange and the word’s final value. This isolated word is an instruction experiment, not a complete lock: ownership, interrupt control and ordering come next.

C reminder: arguments and return values

A call such as f(x) passes an argument to a function. return supplies its result. In a nested call, the inner result becomes an argument to the outer call; assigning the result to a variable can make that easier to read.
