An atomic swap returns the old value

Observe the read-and-write operation used to claim a spinlock.

Compiler and kernel run locally.
Your source stays in this browser.

A spinlock needs to test whether a word is free and claim it as one indivisible operation. A separate load followed by a store would let two CPUs both observe zero before either stores one.

xv6 uses an atomic exchange: it writes 1 and returns the previous value. Returning 0 means this attempt claimed an unlocked word; returning 1 means someone already held it. acquire repeats the exchange until it observes 0.

The native instruction helper executes the real atomic operation. Build and observe old values 0,1 with a final word of 1. Changing the second new value changes what gets stored, while its return still reports the preceding 1. This isolated word is an instruction experiment, not a complete lock: ownership, interrupt control and ordering come next.

C reminder: struct members and output arguments

The dot operator reads a member of a struct value. &st passes its address so fstat can fill it. Check that the call succeeded before reading those fields; declaring a local struct alone does not initialise its contents.

struct stat st;
if (fstat(fd, &st) == 0)
  printf("links=%d\n", st.nlink);
