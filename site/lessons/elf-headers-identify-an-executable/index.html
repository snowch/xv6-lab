An ELF header identifies an executable

Read the real file header checked by exec.

exec does not execute a C source file or arbitrary text. It reads an Executable and Linkable Format (ELF) file. The file contains a header, a table of loadable regions and bytes to load. A fixed byte sequence, the magic value, identifies the format.

The kernel probe opens the actual lab executable, locks its inode and reads its header with readi. The probe reports whether the selected file starts with the required bytes.

Magic is only the first check. This pinned loader also checks segment sizes, address overflow and alignment as it loads. It assumes the course’s RV64 executable format; recognizing a magic word alone is not a complete general-purpose ELF validation policy.

C reminder: pointers and the -> operator

For a pointer p to a struct, p->pid means (*p).pid: follow the pointer, then read its pid member. Use the dot operator with a struct value itself. Reading a member and assigning to it are different operations.

p->pid        // read a member through a pointer
p->pid = 7;   // assign a new member value
