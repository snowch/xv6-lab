Two names can identify one inode

Observe hard links and separate link counts from open references.

A hard link adds another directory name for the same inode. does not copy the file’s bytes into an independent file.

fstat reports metadata for an open descriptor. The example compares inode numbers before and after removing the first name, and reads the contents through the second name.

The inode number agrees, the data remains Hi, and the remaining link count is one. Open descriptors also retain references, but they do not add directory links to nlink.

C reminder: struct members and output arguments

The dot operator reads a member of a struct value. &st passes its address so fstat can fill it. Check that the call succeeded before reading those fields; declaring a local struct alone does not initialise its contents.

struct stat st;
if (fstat(fd, &st) == 0)
  printf("links=%d\n", st.nlink);
