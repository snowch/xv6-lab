Truncation releases a file’s block map

Distinguish removing file data from removing a directory name.

O_TRUNC keeps a file’s name and inode but discards its data. itrunc frees the direct data blocks, follows and frees every indirect entry, frees the indirect table, clears pointers and records a size of zero.

The program writes thirteen blocks, closes the file and reopens it with O_TRUNC. The console reports the reopened file’s size and directory-link count.

This differs from unlink, which removes a name and decrements the link count. Unlink may defer reclamation while references remain; truncation deliberately changes the still-named file’s data. Both must coordinate inode locking, bitmap changes and logging.

C reminder: headers and flag bits

#include makes declarations and constants available to the compiler. The | operator combines flag bits. It differs from ||, which evaluates a logical condition. xv6 defines the meanings of these particular open flags in its own header.

O_CREATE | O_RDWR | O_TRUNC
