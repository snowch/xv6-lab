The kernel translates user pointers before copying

Follow a checked user-memory copy through walkaddr and its U-bit check.

A user pointer names an address in the user page table. The kernel is running under a different page table, so treating that number as an ordinary kernel pointer would not perform the required user-address translation.

copyin rounds the source down to a page boundary, asks walkaddr for a permitted user translation, then copies through the physical page’s kernel mapping. walkaddr rejects invalid mappings and entries without U. copyout performs the reverse data transfer using the same translation helper.

The starter copies from the guard page to show the error from a checked kernel operation. The user program does not attempt a load from that address. This pinned walkaddr checks V and U; its source does not add a separate W-bit check for copyout.

C reminder: a destination passed by address

&byte supplies the address of the kernel’s local variable, letting copyin write into it. The function’s returned integer is a separate result. Check that result before treating the destination as successfully filled; an initialized local value alone does not prove the copy succeeded.

char byte = 0;
int result = copyin(table, &byte, source, 1);
