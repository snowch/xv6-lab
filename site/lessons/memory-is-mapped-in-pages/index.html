Memory is mapped in pages

Connect adjacent user addresses with the kernel’s page mappings.

Compiler and kernel run locally.
Your source stays in this browser.

xv6 manages user memory in pages of 4096 bytes. A page table connects a process’s virtual pages to physical memory pages and records their permissions.

This example requests two pages. is one page beyond p[0]. Both addresses work because the growth operation creates the needed mappings.

In the kernel loop, a is a user virtual address and mem is a newly allocated physical page. mappages connects the two. Adjacent virtual pages do not have to be adjacent in physical RAM.
