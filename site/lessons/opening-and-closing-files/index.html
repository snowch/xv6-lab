A descriptor is a process-local handle

Observe open allocate a descriptor and close make that slot reusable.

A file descriptor is a small integer indexing the calling process’s open-file table. We used descriptor 1 for standard output. allocates another slot and connects it to an open file.

O_CREATE creates a missing file, O_RDWR allows reading and writing, and O_TRUNC empties an existing regular file. These constants come from xv6’s fcntl.h.

The example opens a file, closes that descriptor, then opens the file again. xv6 searches from the lowest free slot, so this run reuses the number. Closing a descriptor releases a handle; it does not remove the file’s name.

C reminder: headers and flag bits

#include makes declarations and constants available to the compiler. The | operator combines flag bits. It differs from ||, which evaluates a logical condition. xv6 defines the meanings of these particular open flags in its own header.

O_CREATE | O_RDWR | O_TRUNC
