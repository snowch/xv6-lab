Paging is enabled during boot

Observe the translation mode before and after the kernel installs its page table.

Compiler and kernel run locally.
Your source stays in this browser.

RISC-V distinguishes machine, supervisor and user privilege. start prepares a return into supervisor mode, where the kernel runs. It also writes zero to satp, the register controlling supervisor address translation: paging initially starts disabled.

main first builds the kernel page table with kvminit, then installs it with kvminithart. The top four bits of satp encode its translation mode: 0 means Bare, and 8 means Sv39. The next chapter follows the page-table structure behind that mode.

The observation runs just after kinit, before the page table is installed. Build and expect mode 0. The browser C compiler uses a small native helper implementing the exact r_satp instruction from riscv.h; the returned value comes from this running CPU.

C reminder: shifts, masks and casts

Right-shifting an unsigned 64-bit value moves its high bits down. A mask selects particular bits; a cast converts the resulting value to the requested C type. Here shifting by 60 extracts the top four mode bits, then the int cast supplies printf’s %d argument.

int mode = (int)(value >> 60);
