EOF needs an empty pipe and closed writers

Distinguish buffered bytes from end of file.

A read returning 0 indicates end of file, or EOF. A pipe reaches this condition when its buffer is empty and no write-end references remain open.

Closing the writer does not throw away buffered bytes. The first read still obtains ok. The next read returns zero because those bytes are gone and no writer can supply more.

EOF is a state, not a special character inserted into the data. An empty pipe with an open writer instead makes a reader wait.

C reminder: buffers and string terminators

The array has six char elements, initially all zero. Reading at most five bytes leaves the final element zero, so the displayed text remains terminated. read reports bytes obtained; it does not append a C string terminator for you.

char buf[6] = {0};
int n = read(fd, buf, 5);
