A path starts at root or the current directory

Follow directory traversal from its selected starting inode.

A directory is a file containing name-to-inode-number entries. Path traversal resolves one component at a time, locking each directory while checking its type and looking up the next entry.

namex starts at the root inode when a path begins with /. Otherwise it takes a reference to the process’s current directory. chdir changes that process reference; it does not move files or rewrite their names.

The program creates item at root containing R and notes/item containing S, then enters notes. The starter looks up the relative name item. Both final components have the same name, but traversal reaches different inodes.

C reminder: strings and byte counts

A C string is a character array ending with a zero byte. The newline escape \n is one byte. A byte-counted write uses the count you pass; it does not search for the string terminator.

char text[] = "hello\n";
// Six message bytes, followed by one zero terminator.
